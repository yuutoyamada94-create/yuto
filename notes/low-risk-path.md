# キャッシュがない状態での、リスクを取らない立ち上げ方

作成日: 2026-10-02
前提: `free-tool-data-cash-points.md` の続き。会社に手元資金がない。自分の財布で立て替えや貸し倒れのリスクは取れない。
検討中の案: ツール代は無料、AI導入支援で稼ぐ。

---

## 0. 結論

- 「ツール無料＋導入支援で稼ぐ」は正しい。それが金の流れモデルの **第0段階** 。
- 金の流れで稼ぐのに、自分の金は要らない。**提携先の金で、紹介料を取る** 形なら、資本ゼロ・貸し倒れゼロ。
- 自分の金を使うのは、外部資本が入った後か、永遠にやらなくてもいい。チャネルのままでも十分稼げる。
- リスクは「金」より「作ってしまうこと」にある。**ツールは作る前に売る。** 手作業＋AIで10社回してから、繰り返す部分だけ製品にする。

---

## 1. リスクの正体を分ける

| リスクの種類 | 内容 | 取るか |
|---|---|---|
| 信用リスク | 立て替えた金が戻らない | **取らない。** 提携先に持たせる |
| 資本リスク | 立て替えに数億円の枠が要る | **取らない。** 外部資本が入るまでやらない |
| 開発リスク | ツールを作ったが使われない | **取らない。** 作る前に売る。手作業で検証 |
| 営業リスク | 客が取れない | 取る。ただし成果報酬と事例で小さくする |
| 時間リスク | 導入支援が本業になり、複利が効かない | 取る。ただし後述の2つの条件で防ぐ |

「リスクを取らない」とは、上の3つを取らないこと。下の2つは、どのみち取るしかない。

---

## 2. 第0段階（0〜6ヶ月）: 導入支援で食う。ただし条件つき

### 2.1 商品
ツールは無料。金を取るのは **「導入」と「運用」** 。
| 商品 | 内容 | 価格の考え方 |
|---|---|---|
| 導入パッケージ | 出面・請求・受付の整理。既存の道具（スプレッドシート、LINE、今の会計ソフト）＋AIの自動化で組む | 固定額。成果物を定義する。時間売りにしない。補助金（デジタル化・AI導入補助金はコンサル費も対象）で客の負担を下げられる |
| 取りこぼしゼロ | 問い合わせ・応募の即応、日程確保、見積一次回答 | 月額＋成果報酬。保証できる変数にだけ紐づける |

AIが作業をやるので、原価はほぼゼロ。粗利は高い。これが「食い扶持」。

### 2.2 ツールは作らない（最初は）
- 最初の10社は、手作業＋AIで回す。裏側がスプレッドシートでも社長には関係ない。
- 10社で「毎回同じ作業」が見えてから、その部分だけを製品にする。
- 作ったものを無料で配る。この時点で「無料ツール」が初めて存在する。
- これなら開発費はほぼゼロで、使われないものを作るリスクが消える。

### 2.3 導入支援が「本業」にならないための2つの条件
導入支援は賞味期限2〜4年の過渡期の仕事。これを終着点にしないために、全ての案件に2つの条件を課す。
1. **導入が終わった時、出面と請求のデータが毎日流れている状態になっていること。** これがないなら、その案件はただのコンサルで、次につながらない。
2. **提携先の金融商品が、その会社のツール上から申し込める状態になっていること。** 使うかどうかは社長次第。入口だけ置く。

この2つが揃っていれば、導入支援の売上を取りながら、同時に第1段階の仕込みが終わっている。

---

## 3. 第1段階（3〜12ヶ月）: 他人の金で、金の流れに乗る

### 3.1 仕組み
```
社長が請求書を作る → 画面に「今すぐ現金化（提携先）」のボタン
→ 社長が押す → 提携先が審査して立て替える → 提携先の手数料のうち、一定割合がうちに入る
```
うちは1円も立て替えない。貸し倒れも提携先が負う。
うちが提供するのは **入口（社長が毎日使う画面）と、データ（出面・請求履歴で審査が速く通る）** 。

### 3.2 提携先の種類
| 流れ | 提携先の例 | うちの収益 |
|---|---|---|
| 早期入金 | 請求書の早期資金化サービス各社（OLTA、ペイトナー、GMOの掛け払い系など） | 紹介料、またはデータ連携料。手数料の一部 |
| 職人前払い | 給与前払いサービス各社 | 紹介料、または導入手数料 |
| 保険 | 損保の代理店、または代理店と提携 | 代理店手数料 |
| 資材 | 問屋・メーカー | 販売奨励金。在庫は持たない |

### 3.3 いくらになるか（提携のまま）
田中設備（年商2億）の例で、自社金融なら月10万円だったものが、提携なら月2〜4万円程度。
少なく見えるが、**資本ゼロ、貸し倒れゼロ、営業コストほぼゼロ** で、社長が使い続ける限り入り続ける。
50社で月100〜200万円。これに導入支援と取りこぼしゼロの売上が乗る。

### 3.4 提携先への交渉材料
提携先から見ると、うちは「現場企業に毎日触っている入口」と「審査を速くするデータ」を持っている。
普通の紹介より紹介料を高く取れる根拠はここ。データ連携で貸し倒れ率が下がるなら、その分を分けてもらう交渉ができる。

---

## 4. 第2段階（12ヶ月〜）: 自分の金を使うかどうかは、後で決める

- 提携のままでも事業は成り立つ。無理に内製化しない。
- 内製化するのは、次の3つが揃った時だけ。
  1. 50〜100社のデータで、貸し倒れ率が提携先より明らかに低いと示せる
  2. 外部資本（出資、銀行の枠、金融機関との合弁）が入る
  3. 規制対応（貸金業、ファクタリングの枠組み）を専門家と設計済み
- 揃わなければ、チャネルのまま承継（第4段階）に進む。承継は「流れを握る」ことの終着点であって、金融の内製化は必須ではない。

---

## 5. 最初の12ヶ月の売上の形（15社の場合、仮置き）

| 収益源 | 仮定 | 12ヶ月の売上 |
|---|---|---|
| 導入パッケージ | 15社 × 40万円 | 600万円 |
| 取りこぼしゼロ（月額＋成果） | 15社 × 月4万円 × 平均6ヶ月 | 360万円 |
| 提携金融の紹介料 | 立ち上がりが遅いので控えめに | 50〜100万円 |
| 合計 | | **約1,000〜1,050万円** |

原価は、AIの利用料と、自分の時間と、業種パートナーへの分配。
立て替えゼロ、開発費ほぼゼロ、貸し倒れゼロ。これなら手元資金がなくても回る。
そして12ヶ月後には、15社分の出面・請求データと、提携金融の入口が全社に置かれている。

---

## 6. 守るべき3つの指標（導入支援に埋もれないために）

| 指標 | 目標 | 意味 |
|---|---|---|
| 出面データが毎日流れている顧客の割合 | 80%以上 | データ取得面として機能しているか |
| 提携金融の入口が置かれている顧客の割合 | 100% | 流れへの接続ができているか |
| 提携金融を1回以上使った顧客の割合 | 12ヶ月で30% | 流れで稼ぐ段階に入れているか |

導入支援の売上がいくら伸びても、この3つが低ければ、それはただのコンサル会社になっている。

---

## 7. 一言で

自分の金は使わない。他人の金の流れの「入口」に立って、紹介料を取る。
ツールは作る前に売り、手作業で10社回してから製品にする。
導入支援は食い扶持として正しい。ただし全案件で「データが流れる」「金融の入口が置かれる」の2条件を守る。

---

## 8. 「ツール無料＋導入無料、優秀な事務員つきで月20万円」の評価

### 8.1 正しい点
- **価格を「ソフト」ではなく「人」に置いている。** 現場の社長はソフトに月2万円を払いたがらないが、事務員に月20万円を払うのは慣れている。正社員の事務員は社保込みで月25〜35万円。パートでも12〜15万円で、しかも夜と休日は動かない。「24時間動く事務員が20万円」は比較の土俵が有利。
- 資本ゼロ、貸し倒れゼロ、AIが作業するので原価が低い。15社で月300万円、年3,600万円。手元資金がなくても会社になる。
- 事務員が請求書を作るので、後で「今すぐ現金化」のボタンを置く導線が自然に残る。金の流れへの入口が消えない。
- 社長が「雇った」感覚になる。「人を大切にする」価値観と相性がいい。紹介の時も「うち、いい事務さん入れたんだよ」と言える。

### 8.2 詰めるべき5点

**1. 無料の終わりを決める。**
「価値を感じるまで無料」は、終わりがないと永遠に無料になる。
→ 「導入＋30日間は無料。31日目から事務員つきで月20万円」と最初に言う。義理の文化では、ちゃんと働いた相手に払わないのは気持ち悪い。期限を切った方が転換率は上がる。

**2. 事務員の「職務記述書」を作る。これが営業資料。**
社長は「AI」は買わないが「この人、何やってくれるの？」には反応する。本物の採用と同じように、仕事の中身を一枚にする。
| 担当 | 中身 |
|---|---|
| 受付 | 電話・LINE・フォームの問い合わせと求人応募に、24時間、数分で一次対応。面接と現地調査の日程を押さえる |
| 出面・日報 | 職人からLINEや写真で来た報告を集計。誰がどの現場に何日入ったかを毎日確定 |
| 見積 | 社長の一言から下書きを作る。過去の単価を引く |
| 請求・入金 | 月末に請求書を作って送る。入金を照合し、未入金を社長に知らせる |
| 支払い | 資材屋・外注先の支払い予定を一覧にし、期日前に知らせる |
| 書類 | 安全書類、労務の定型書類の下書き |
| 報告 | 月1回「今月、社長の時間を◯時間返しました」「未入金◯件」「応募◯件」の一枚 |
受付が入っているのが重要。「取りこぼしゼロ」を事務員の仕事の一部にすると、20万円の価値が一目で分かる。

**3. 価格は2段階にする。**
職人5人の会社と30人の会社で、事務の量は違う。1本の価格だと小さい会社には高く、大きい会社には安すぎる。
| 規模 | 月額 | 目安 |
|---|---|---|
| 職人10人まで | 12〜15万円 | パート事務の代わり |
| 職人11〜30人 | 20〜25万円 | 正社員事務の代わり |
それ以上は個別。3段階以上にはしない。社長が覚えられない。

**4. 窓口はLINE。ツールの画面は裏側。**
社長も職人もLINEで生きている。事務員に名前をつけて、LINEで話しかければ動く形にする。ツールの画面は「見たい時に見るもの」でいい。これで導入の摩擦がほぼ消え、作るものも小さくなる。

**5. 例外処理の人間を最初から置く。**
AIは8割を処理するが、残り2割（変な請求、揉めている入金、感情的な電話）は人間が要る。
→ 10社につき1人の「例外デスク」（最初は自分、次にパート）を原価に入れる。
→ 金に関わる出力（請求書、入金照合）は人間が一度見てから出す。ここでミスると義理の文化では一発で終わる。

### 8.3 1社あたりの原価と粗利（仮置き）
| 項目 | 月額 |
|---|---|
| 売上 | 20万円 |
| AI・電話・ツールの実費 | 1〜3万円 |
| 例外デスクの人件費の按分（10社で1人30万円） | 3万円 |
| 粗利 | **約14〜16万円（70〜80%）** |

### 8.4 解約を防ぐもの
- 月1回の報告で「返した時間」と「取りこぼさなかった件数」を数字で見せる。社長はこれを仲間に見せる。
- 電話番号とLINEの窓口を事務員が持っている状態にする。辞めさせると電話が止まる。
- データ（出面・請求の履歴）がこちらにある。移すのが面倒。
- 社長の子どもや本物の事務員が入っても、「受付と夜間」は残る設計にする。

### 8.5 ファクタリングという言葉について
構造は近いが、現場の社長の前では **「ファクタリング」という言葉は使わない。** 悪徳業者の印象が強い。
その段階が来たら「請求書の早期入金」「元請けの支払いを待たずに現金に」と言う。提携先も、元請けに通知する3社間の形か、保証のある形を選ぶ。

### 8.6 一言で
「事務員つきで月20万円」は正しい。ソフトではなく人の値段で売る。
無料の期限を切り、職務記述書を営業資料にし、価格は2段階、窓口はLINE、例外処理の人間を原価に入れる。
