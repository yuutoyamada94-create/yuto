# 現場経営者に刺さる訴求・パッケージ・紹介とストックの設計

作成日: 2026-10-02
前提: `my-bet-blue-collar-ai.md` の続き。
対象: ブルーカラー業種の経営者。価値観は「大義名分」「義理を通す」「人を大切にする」。
ボトルネックは「採用」と「元請け・紹介依存の受注」。
狙い: 紹介で回り、ストックで積み上がる事業。

---

## 0. 設計の核（これだけは外さない）

1. **AIを売らない。「人が来る会社」「指名で仕事が来る会社」を売る。** AIは裏側の手段。
2. **社長を主役にする。** 社長の顔と言葉を発信の中心に置く。これが採用コンテンツであり、紹介の道具であり、社長の誇りになる。
3. **紹介は「金」ではなく「義理」で回す。** 紹介料は払わない。紹介者が「与える側」になれる設計にする。
4. **地域×業種で1社だけ。** 同じ市で同業は取らない。義理が立ち、希少になり、紹介は異業種と隣の地域へ流れる。
5. **「採用」で終わらせず「定着」まで持つ。** 人を大切にする社長は、辞められることが一番つらい。ここにストックが乗る。
6. **顧客同士をつなぐ。** 紹介依存を否定するのではなく、顧客の間で仕事を回す網を作る。これが最大のストックで堀。

---

## 1. この経営者に「刺さる言葉」と「刺さらない言葉」

### 1.1 刺さらない
効率化、DX、AI導入、生産性、コスト削減、自動化、マーケティング、リード、CVR。
これらは「人を減らす」「よそ者の言葉」「うちには関係ない」に聞こえる。

### 1.2 刺さる（価値観ごと）

| 価値観 | 刺さる訴求 | 中身 |
|---|---|---|
| 大義名分 | 「この仕事を次の世代に残す」「若い子が誇れる会社にする」「職人の仕事を正当な値段で売る」 | 業界の存続、技術の継承、下請け構造からの脱却 |
| 義理 | 「元請けに頭を下げ続けなくていいように、直接の客を持つ」「紹介してくれた人の顔を潰さない体制を作る」「世話になった人に、仕事で返す」 | 自立と、関係を守ること |
| 人を大切に | 「社長が夜中にやってる事務を、職人と現場に返す」「採るなら、辞めない人を採る」「給料を上げられる会社にする」 | 社長の時間、従業員の定着と待遇 |

### 1.3 一言の看板（例）
- 「〇〇業の、人が来る会社づくり」
- 「指名で仕事が来る〇〇屋になる」
- 「職人を、ちゃんと食わせる会社に」

「採用代行」「集客支援」とは言わない。結果の状態を言う。

---

## 2. パッケージ設計: 「人が来て、指名が来て、辞めない会社」3段階

### 2.1 第1段階「顔が見える」（0〜3ヶ月、成果報酬＋少額月額）
- 社長と職人の発信（SNS、動画、採用ページ）。AI組織で制作・運用、社長は月1回話すだけ。
- 求人の設計（仕事の中身、給料、1日の流れ、社長の考え）を正直に見せる。
- 応募対応、面接設定までをAIで即応。現場は電話に出られないので、ここが効く。
- **課金**: 応募1件、採用1人の成果報酬。事例ができるまで最初の3社は安く。
- **30〜60日で見える勝ち**: 「応募が来た」「若い子が面接に来た」「ホームページ見て直接電話が来た」。これが紹介の種。

### 2.2 第2段階「指名が来る」（3〜12ヶ月、月額）
- 施工事例、お客の声、地域の検索対策、口コミ対応をAI組織で蓄積。
- 元請け依存の比率を下げ、直接受注の比率を数字で見せる。
- 見積・問い合わせ対応の即応化。
- **課金**: 月額の運用料。資産（事例・口コミ・検索順位）が積み上がるので解約しにくい。
- **顧客への見せ方**: 「元請け比率 80% → 60%」のような数字を四半期で報告。社長はこの数字を仲間に自慢する。

### 2.3 第3段階「辞めない」（6ヶ月〜、月額）
- 給与と評価の見える化、職人のキャリアの道筋、面談の記録。
- 社長の考え（理念）→ 会社の目標 → 各職人の役割 を構造化して保持する。ここにAddnessで培った組織OSの知見が直接乗る。
- 退職理由の先回り（給与不満、将来不安、人間関係）を社長が把握できる状態にする。
- **課金**: 月額。人数が増えるほど単価が上がる設計。
- **意味**: 採用は定着しないと社長にとって損失。定着まで持つと「人を大切にする」価値観に本当に応えたことになり、紹介の理由になる。

### 2.4 第4段階（将来）「つなぐ・残す」
- 顧客同士の仕事の融通（下記3章）。
- 後継者不在の顧客の承継、または資本参加。

## 3. 紹介が「自然に起きる」仕組み

### 3.1 紹介の原理（この文化では）
紹介は「頼むから起きる」のではなく、次の条件が揃うと起きる。
1. **社長に語れる話がある**（「うちに若い子が入った」「直接電話が来た」）
2. **語ると社長が格好よく見える**（自分の決断の成功談）
3. **紹介先に対する義理になる**（困っている仲間を助ける行為）
4. **紹介した自分の顔が潰れない**（サービスの質が保証されている）
5. **語る場がある**（会、現場、飲み会、組合）

### 3.2 設計
| 仕組み | 内容 |
|---|---|
| 社長を主役にしたコンテンツ | 社長の動画・記事は、採用コンテンツであると同時に「仲間に見せたくなるもの」。社長が自分で拡散する |
| 数字の四半期報告 | 「応募◯件」「直接受注比率◯%」「定着率◯%」を1枚にして渡す。社長はこれを見せて語る |
| 紹介者が「与える側」になる | 紹介で来た会社は初月無料、または診断無料。紹介者は「俺の紹介なら安くなる」と言える。紹介料は払わない。金で義理を汚さない |
| 紹介者の顔を守る保証 | 「成果が出なければ請求しない」を紹介案件に適用。紹介者は安心して勧められる |
| 感謝を公の場でする | 会や発信で「〇〇社長のご紹介で」と名前を出す（本人の了承のもと）。義理に対する最大の返礼は名誉 |
| 「頼み方」を変える | 「紹介してください」ではなく「同じ悩みの社長がいたら、うちのこと話してやってください」。頼むのではなく託す |

### 3.3 紹介が流れる方向を設計する
地域×業種で1社しか取らないので、紹介は **同じ地域の異業種** と **隣の地域の同業** に流れる。
- 電気屋が水道屋を紹介する（同じ現場で顔を合わせている）
- 市内の設備屋が隣の市の設備屋を紹介する（組合や学校のつながり）
これを前提に、「地域の職人ネットワーク」を1社目から意識して作る。

---

## 4. 最大のストックで堀: 顧客同士で仕事を回す網

「紹介での受注しかない」というボトルネックは、紹介を否定して解決するのではなく、**紹介を系統立てて自分の網にする** ことで解決する。

### 4.1 構造
- 同じ地域で、電気・設備・塗装・解体・内装・外構などを1社ずつ顧客にする。
- 顧客間で仕事を融通する仕組み（空いた日程、手が足りない現場、専門外の相談）をAIで管理する。
- 施主からの問い合わせ（第2段階で取った直接受注）を、網の中の適切な業種に回す。

### 4.2 なぜ堀になるか
- 顧客にとって、網から抜けると仕事が減る。解約の理由が消える。
- 網が大きいほど1社あたりの価値が上がる。複利。
- 顧客が自分で新しい業種を網に連れてくる（紹介が構造に組み込まれる）。
- 自分は「仕事を回す人」になる。これは需要側を握ることであり、承継の話が向こうから来る位置。

### 4.3 具体の形
- 「〇〇市 職人の会」のような、顔の見える会を四半期に1回。飲み会でいい。
- 会の中で仕事の融通と採用の相談が自然に起きる。それをAIで記録し、次につなげる。
- 会員費は取らない、または少額。会は商品ではなく、紹介と定着とストックの土台。

---

## 5. 信頼を得るための「振る舞い」（商品より重要）

| やること | 理由 |
|---|---|
| 現場に行く。朝に行く。作業着で行く | 「来た人」しか信用されない |
| 電話に出る。折り返しは1時間以内 | 現場の社長はメールを見ない |
| 約束は小さくして、必ず守る | 義理の文化では、守れなかった約束が全てを壊す |
| 「AI」を前に出さない。聞かれたら答える | AIは「人を減らす」に聞こえる |
| 業種内部の人を横に置く | 言葉と作法が分かる人がいないと信用されない |
| 同じ市で同業を取らない | 義理を守る姿勢そのものが営業になる |
| 社長の名前で紹介を受けたら、その社長に必ず報告する | 紹介者への義理。これを怠ると網は死ぬ |

---

## 6. 顧客の選び方（紹介は価値観の同じ人の間でしか起きない）

全ての社長を相手にしない。次の条件に合う社長だけを取る。
- 従業員を「うちの子」と呼ぶ
- 元請けへの不満と、自立への意思がある
- 若い人を入れたいと本気で思っている
- 自分が表に出ることに抵抗がない（または説得できる）

合わない社長を取ると、成果も紹介も出ず、網の質が下がる。最初の3社の選定が全てを決める。

---

## 7. 測るもの

| 指標 | 意味 |
|---|---|
| 初回の「語れる勝ち」までの日数 | 30〜60日以内が目標。遅いと紹介が起きない |
| 顧客ごとの紹介件数 | 1顧客あたり年1件以上なら網は自走する |
| 直接受注比率の変化 | 第2段階の成果 |
| 定着率（採用後12ヶ月） | 第3段階の成果 |
| 網の中で融通された仕事の件数 | 堀の強さ |
| 月額の継続率 | ストックの健全性 |

---

## 8. 落とし穴

- **AIの話をしてしまう。** 社長が聞いているのは「人」と「仕事」の話。
- **成果を急いで嘘をつく。** 義理の文化では一度の嘘で終わる。
- **紹介料を払う。** 関係を金に変えた瞬間、紹介が止まる。
- **補助金を前に出す。** 補助金目当ての社長が来て、網の質が下がる。
- **業種を広げすぎる。** 1業種で型ができる前に広げると、全部が中途半端になる。
- **社長が表に出ない会社を無理に取る。** 発信が成立しない。

---

## 9. 一言で

AIを売らず「人が来て、指名が来て、辞めない会社」を売る。
社長を主役にし、数字を持たせ、紹介者が与える側になれる形にする。
地域×業種で1社に絞り、顧客同士で仕事を回す網を作る。網そのものがストックで堀で、承継への入口になる。
