# 業界入門: 残土運搬・処分・産廃収集運搬（ダンプ業）の仕組み

作成日: 2026-10-03
目的: 五幸建材工業のような会社が「何を、誰に、いくらで売り、どこで儲け、何に困っているか」を一枚で掴む。
数字は首都圏の目安。会社・現場・土質で大きく変わる。訪問前の仮説として使う。

---

## 0. 一言で

**「土を運ぶ」運送業と、「土を受け入れる場所」を貸す不動産業の2階建て。**
運ぶ側は「車両×運転手×時間」を売る薄利の商売。受け入れる側は「有限の穴」を売る高粗利の商売。
五幸は両方を持っている。これが普通のダンプ屋との違いで、強さの源泉。

---

## 1. プレイヤーと金の流れ

```
施主（家を建てる人、発注者）
   │  残土処分費として 7,000〜8,000円/m3 程度を払う（ハウスメーカーの見積に入っている）
   ▼
元請け（ハウスメーカー、ゼネコン、工務店）
   │  マージンを抜いて、工事ごと下請けに出す
   ▼
一次下請け（基礎屋、土工屋、解体屋、外構屋）
   │  掘るのは自分。運ぶのはダンプ屋に頼む（自社ダンプを持つ会社もある）
   ▼
ダンプ会社（五幸の「運ぶ」側）        ← 運搬費 3,000〜5,000円/m3（10km目安）、または車建て
   │
   ▼
処分場・受入地（五幸の「受け入れる」側） ← 受入費 3,000〜6,000円/m3（土質で変わる）
   ・ストックヤード（一時保管・再利用）
   ・土質改良プラント（改良土にして販売 2,000円台/m3）
   ・埋立・造成地
```

ポイント:
- 施主が払う額と、現場で実際に動く額の差（マージン）が各層で抜かれる。ダンプ屋は下の方。
- **処分場を持つと、他のダンプ屋が客になる。** 運ぶ会社は競合だが、受け入れる会社にとっては顧客。五幸はこの位置。
- 元請け（ハウスメーカー）との取引は安定するが、単価は叩かれ、支払サイトは長く、支店ごとに書式が違う。

## 2. 商品の単位と価格（首都圏の目安）

### 2.1 運搬
| 単位 | 価格 | 備考 |
|---|---|---|
| 車建て（1台1日） | 4t: 1.2〜2万円 ／ 10t: 6〜9万円 | 運転手込み。燃料・処分費は別のことが多い |
| m3建て | 3,000〜5,000円/m3（10km目安） | 距離ではなく **1往復の拘束時間** で決まる |
| 待機料・追加料 | 現場の積込待ち、処分場の受入待ちなどで発生 | **請求漏れが多い。** 日報が正確なら取れる |

### 2.2 受入（処分場側）
| 土質 | 受入単価の目安 | 備考 |
|---|---|---|
| 第1〜3種建設発生土（良い土） | 2,000〜4,000円/m3 | 再利用しやすい |
| 第4種・泥土（悪い土） | 5,000〜6,000円/m3以上 | 改良が要る |
| 改良土の販売 | 2,000円台/m3 | 受け入れた土を改良して売る。二重に稼ぐ |

10tダンプ1台で5〜6m3運ぶので、1台の受入で2〜3万円。処分場に1日100台入れば200〜300万円/日。**穴を持つ会社が儲かる理由。**
ただし穴は有限。埋まれば終わり。許認可と近隣と規制で、新しい穴は作りにくい。だから既存の処分場の価値は上がり続けている。

### 2.3 産廃（別物）
残土（建設発生土）は廃棄物ではなく「建設副産物」。収集運搬の許可もマニフェストも不要。
ただし、がれき・木くず・汚泥が混じると産業廃棄物になり、都道府県ごとの収集運搬許可とマニフェストが必要。五幸は東京都・神奈川県の許可を持っているので、両方運べる。
→ 事務の負荷は産廃側に集中する（マニフェスト、契約書、許可の更新）。

## 3. ダンプ1台の経済（10t、1日、目安）

| 項目 | 金額 |
|---|---|
| 売上（車建て） | 6〜9万円 |
| 運転手の日給 | 1.5万円（＋社保・手当） |
| 燃料 | 1〜1.5万円（走行距離次第） |
| 車両（償却・リース） | 0.5〜1万円 |
| 保険・修理・タイヤ・車検 | 0.5〜1万円 |
| 残る利益 | **1.5〜3万円/台/日** |

全ては **回転数** で決まる。1日4往復できる現場と2往復しかできない現場で、利益が2倍違う。
回転数を殺すのは「待機」。現場で積込を待つ、処分場で受入を待つ、道が渋滞する。
だから配車（どの車を、どの現場に、どの処分場に、何時に）が利益そのもの。

五幸の規模感（仮）: 30名で車両20〜25台とすると、運搬だけで年2〜4億円。処分場の受入が別に乗る。

## 4. 1日と1ヶ月の流れ

### 1日
```
前日夕方   元請け・基礎屋から翌日の依頼（電話・FAX・LINE）: 現場、時間、台数、土質、処分先
           → 配車担当が配車表を組む。ここに電話が集中する
早朝       車庫出発。現場へ
現場       土工屋のバックホウが積む。伝票（受領印）
処分場     受入。伝票（受入票）。土質で単価が変わる
往復       1日2〜4回転
夕方       日報（車番、現場、往復回数、処分先、待機時間）。紙が多い
夜勤       都心の夜間工事、道路工事。夜も配車と電話がある
```

### 1ヶ月
```
月末       伝票を車両別・現場別・得意先別に束ねる
           元請け（ハウスメーカー）は支店ごとに書式が違う。車建てとm3建てが混在
           待機料・追加料の請求漏れが出やすい
翌月       請求書送付
翌々月末   入金（月末締め翌々月払いが多い）→ 2ヶ月の立替
```

## 5. 規制と、この業界固有のリスク

| 論点 | 内容 | 会社への影響 |
|---|---|---|
| 盛土規制法（2023年施行） | 熱海の土石流を受け、盛土・残土処分の規制強化 | 処分場の新設が難しくなり、既存の処分場の価値が上がる。受入側の書類も増える |
| 自治体の残土条例 | 一定量以上の搬入に届出、土質検査 | 受入側の事務 |
| 産廃混入 | 残土にがれき等が混じると産廃扱い | 許可・マニフェストが必要。誤ると違法 |
| 2024年問題 | 運転手の時間外労働の上限（年960時間） | 拘束時間の記録と管理が必須。日報が重要に |
| 過積載 | 10tに10t以上積む | 取り締まり。運転手と会社の責任 |
| ナンバー | 他社の土を有償で運ぶなら貨物運送の許可（緑ナンバー）が原則 | 業界に曖昧な部分がある。確認ポイント |
| 運転手の高齢化・不足 | 平均年齢が高く、若手が入らない | 採用が構造的な痛み |

## 6. この業種で「事務」が効く場所（金に直結する順）

| 場所 | なぜ金になるか |
|---|---|
| **待機料・追加料の請求漏れをなくす** | 日報に待機時間が正確に残れば、請求できる。月に数十万円単位で変わることがある |
| **配車の電話を取りこぼさない** | 前日夕方の依頼を1件落とすと、翌日1台が空く。空いた車は赤字 |
| **月末の請求を早く正確に** | 車建て・m3建て・支店別書式を手でやると、締めから請求まで10日以上かかる。入金が遅れる |
| **拘束時間の集計** | 2024年問題の対応。手集計だと管理できない |
| **処分場の受入予約と時間調整** | 受入待ちが減れば回転数が上がる |
| **産廃マニフェストの入力・照合** | 法定。ミスすると許可に響く |

→ 「事務員つき」の提案は、この業種では「請求漏れが減る」「車が空かない」という **売上の話** にできる。コスト削減の話にしなくていい。

## 7. 業界の構造変化（2026〜）

- **処分場が希少化する。** 盛土規制法で新設が止まり、既存の穴の価値が上がる。処分場を持つ会社は強くなる。
- **運転手が足りなくなる。** 高齢化と2024年問題。1台あたりの売上を上げるか、台数を減らすか。
- **後継者不在。** 創業30年超の会社が多く、社長は60代。承継の供給が増える。
- **元請けの支払い条件は変わらない。** 2ヶ月の立替は続く。資金繰りの歪みは構造的。
- **電子化が遅い。** 紙の日報、FAXの依頼、電話の配車が普通。だから事務の自動化の余地が大きい。

---

## 8. 五幸をこの地図に置くと

- 運ぶ側: 3〜10tを揃え、狭い道の現場も取れる。ハウスメーカー多数で安定、ただし単価と支払サイトは厳しい。
- 受け入れる側: 緑区・青葉区に処分場。改良土・砕石も売る。**ここが利益の柱で、他社ダンプが客。**
- 産廃: 両都県の許可。事務の重さはここ。
- 痛み: 事務スタッフが足りない（募集中）、夜の電話が個人の携帯、運転手の採用、月末の伝票、拘束時間。
- 将来: 処分場の価値上昇で会社の価値も上がる。承継の対象として魅力的。

## 9. 訪問時に確認する数字（仮説を事実に変える）

1. 車両台数と内訳（3t〜10t）
2. 1日の平均回転数と、待機が多い現場・処分場
3. 車建てとm3建ての比率
4. 得意先の数と、ハウスメーカーの支店数（書式の数）
5. 月末締めから請求書発送までの日数
6. 待機料・追加料を請求できている割合
7. 日報の形（紙／アプリ）、マニフェストの形（紙／電子）
8. 処分場の1日の受入台数と、残り容量
9. 運転手の平均年齢と、昨年の採用数・退職数
10. 配車担当は誰か、夜の電話は誰に行くか
