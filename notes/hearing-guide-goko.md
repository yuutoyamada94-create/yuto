# 初回ヒアリングの型（「事業相談させてください」で取ったアポ）

作成日: 2026-10-03
前提: `succession-context-goko.md` の続き。知人の会社。専務（息子）が承継中、奥さんが事務を引き継ぐ段階。
目的: 60〜90分で「誰の頭に何が入っているか」「金はどう流れているか」「何に困っているか」を聞き、最後に「紙を預かる」か「月末に同席する」の約束を取る。

---

## 0. この入り方が効く理由

- 「相談させてください」は、相手を先生にする。社長も専務も、自分の仕事を語るのは好き。
- 売る場ではないので、警戒されない。こちらは聞くだけ。
- 聞いた中身がそのまま提案書になる。相手の言葉で書けるので刺さる。
- 「知人の会社に相談しに来た」は、義理の文化で自然な行動。

---

## 1. 事前に決めておくこと

| 項目 | 決め方 |
|---|---|
| 誰に会うか | 専務が本線。できれば奥さんも同席。社長は別の機会（または専務に「社長にも聞きたい」と言ってもらう） |
| 場所 | 事務所。できれば車庫か処分場も見せてもらう。伝票・配車表・日報の現物が見られる |
| 時間 | 平日の午前か、夕方の配車が落ち着いた後。月末は避ける |
| 持ち物 | ノート1冊。資料は持たない。スマホで写真を撮る許可だけ取る |
| 言わない言葉 | AI、DX、効率化、システム、属人化、ツール |
| 自分の立場 | 「現場の会社の事務を手伝う仕事を始めた。業界を知りたいので教えてほしい」 |

---

## 2. 聞く順番（会話の流れで。尋問にしない）

### 2.1 入り（10分）: 会社と人
- 「今、車は何台ですか。3tから10tまで、どんな内訳ですか」
- 「運転手さんは何人、平均年齢はどれくらいですか」
- 「処分場は1日何台くらい入りますか。持ち込むのはどんな業者さんですか」
- 「社長と専務と奥さんで、今どう分担してますか」 ← **誰の頭に何が入っているか** の入口

### 2.2 1日の流れ（15分）: 配車と日報
- 「明日の配車って、いつ、誰から、どうやって来ますか。電話？FAX？LINE？」
- 「それを誰が、どこに書きますか」（配車表の現物を見せてもらう）
- 「運転手さんは1日に何往復くらい。待たされる現場ってありますか」
- 「日報って、どんな形で上がってきますか」（現物を見せてもらう）
- 「伝票は、現場のと処分場のと、どう集めてますか。なくなることあります？」
- 「夜勤の時や現場に出てる時、電話は誰が取ってますか」

### 2.3 月末と金（15分）: 請求と入金
- 「月末締めてから、請求書が出るまで何日くらいかかりますか」
- 「ハウスメーカーさんは支店ごとに書式が違いますか。何種類くらい」
- 「車建てと立米建て、だいたいどれくらいの割合ですか」
- 「待機料って、取れてますか」
- 「入金は締めてからどれくらい後ですか。その間の支払いはどうしてますか」 ← 2ヶ月立替
- 「処分場の方は、現金の業者さんと掛けの業者さん、どっちが多いですか」

### 2.4 道具（5分）: 今使っているもの
- 「会計はどこに頼んでますか。給与計算は？」
- 「ExcelやLINEは使ってますか。配車や日報はスマホ？紙？」
- 「デジタコは10tには付いてますか」
- 「産廃のマニフェストは紙ですか、電子ですか」

### 2.5 承継（15分）: ここが本題。専務に
- 「専務になられて、どのくらいですか。社長からはどんな順番で引き継いでますか」
- 「社長の頭の中にしかないことって、何だと思いますか」（得意先、単価、穴、運転手）
- 「社長が1週間いなかったら、どこで止まりますか」
- 「奥さんが事務を引き継ぐ時、一番困りそうなのは何ですか」
- 「専務が自分の代でやりたいことってありますか」（次の土地、採用、受入の拡大、直接受注）

### 2.6 困りごとの順番（5分）
- 「今、一番困ってるのは、人ですか、仕事ですか、事務ですか、金ですか」
- 「2番目は？」
- 「逆に、うまくいってることは？」 ← 誇りを聞く。ここが社長の言葉になる

### 2.7 締め（5分）: 頼みごとを一つだけ
次のどれか一つ。小さい方から。
1. 「過去3ヶ月分の伝票と請求書、預からせてもらえませんか。1台1日の利益と、穴の土質別の単価を出してみます。1週間でお返しします」
2. 「次の月末、一緒に座らせてもらえませんか。請求を作るところを見せてください」
3. 「処分場、朝に見学させてもらえませんか」

**提案はしない。** 聞かれたら「30日タダで事務員を置かせてもらうこともできます」と一言だけ。

---

## 3. 聞きながら見るもの（現物）

| 現物 | 見るポイント |
|---|---|
| 配車表 | 紙か、ホワイトボードか、Excelか。誰の字か。前日の何時に書かれるか |
| 日報 | 項目に「待機」があるか。提出率。誰が集計しているか |
| 伝票 | 現場の受領印の形式。処分場の受入票の形式（自社発行か）。保管場所（箱？クリップ？） |
| 請求書 | 書式の種類。手書きかExcelか。車建てと立米建ての混在 |
| 事務所の机 | 誰の机に紙が積まれているか。それがボトルネックの人 |
| 電話 | 会話中に何本鳴るか。誰が取るか |
| 処分場 | 受付の仕方。台数。残容量の見た目 |

---

## 4. 聞いてはいけないこと（初回）

- 年商、利益、借入の額（聞かなくても車台数と受入台数で出る。聞くと警戒される）
- 社長の健康、引退時期
- 家族の関係（父と息子の折り合い）
- 他社との比較（「よそはこうしてます」）
- 「なぜ紙なんですか」

---

## 5. 聞いた後（24時間以内）

- お礼のLINEを1本。聞いた中で一番印象に残った「誇り」を一言添える。
- 聞いた内容を `target-goko-kenzai.md` の記入欄に埋める。
- 「誰の頭に何が入っているか」を3人分の表にする。
- 頼みごと（紙を預かる／月末同席／処分場見学）の日程を確定する。
- 提案書はまだ作らない。紙を預かって数字が出てから。

---

## 6. 一言で

「相談させてください」で行き、聞くだけ。
車台数、配車の来方、日報の形、月末の日数、車建てと立米建ての割合、2ヶ月立替、社長の頭の中、専務のやりたいこと。
現物を見せてもらい、最後に「紙を預からせてください」だけ頼む。提案はしない。
