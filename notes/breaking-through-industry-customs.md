# 業界のしきたりを「突破しない」導入設計

作成日: 2026-10-03
前提: `daily-report-design.md` の続き。
論点: 古いしきたり（紙、口頭、義理、日払い、現場主義）がある業界で、無料でも導入は厳しい。どう考えるか。

---

## 0. 結論

- しきたりは突破しない。**迂回する。** しきたりを変えずに、横にデータの層を足す。
- 導入の難しさは「無料かどうか」ではなく **「誰の行動を、どれだけ変えるか」** で決まる。設計を点検すると、変えるのは運転手の「伝票を写真で送る」1動作だけ。それ以外は誰も何も変えない。
- 社長が変化を受け入れるには **大義名分** が要る。「便利だから」では動かない。「法律で記録が要るようになった」「元請けが求め始めた」が、顔を立てたまま変える理由になる。外圧は既に揃っている。
- 最後の砦は **「伝票ボックス」** 。写真すら送らない運転手の分は、夕方に車庫の箱に入れてもらい、こちらが撮る。行動変化ゼロの逃げ道を最初から用意する。
- しきたりは、入った後は **堀** になる。彼らは他のSaaSにも乗り換えない。

---

## 1. しきたりの正体を分ける

| しきたり | 中身 | 扱い |
|---|---|---|
| 紙の伝票 | 現場の受領印、処分場の受入票。元請けとの証拠 | **触らない。** 紙は残す。写真を足すだけ。紙が証拠である限り、紙を無くす提案は拒否される |
| 口頭・電話の配車 | 前日夕方に電話で頼み、配車担当が頭と紙で組む | **触らない。** 配車の判断は人。こちらは聞き取りと入力だけ。しかも最後 |
| 義理の受注 | 「あそこには世話になってる」で赤字現場も受ける | **触らない。** 数字は「交渉の根拠」として渡し、切るかどうかは社長 |
| 日払い・週払い・現金 | 運転手の給与慣行 | **触らない。** むしろ前払いで支える |
| 現場主義（事務を軽く見る） | 「事務は女の子がやるもの」「書類より現場」 | **利用する。** 「社長と運転手を現場に戻す」と言えば、しきたりと同じ方向 |
| 社長の一声で決まる | トップダウン | **利用する。** 朝礼で社長が一言言えば、運転手は動く。説明会はいらない |
| 元請けに逆らわない | ハウスメーカーの書式・条件に合わせる | **触らない。** 元請けに何も頼まない。書式に合わせて作る |
| 「余計なことを増やすな」 | 運転手の本音 | **設計で応える。** 増やすのは写真1枚。減らすのは紙の日報 |

→ 突破しなければならないしきたりは、一つもない。

---

## 2. 「誰の行動を、どれだけ変えるか」の点検

| 人 | 変える行動 | 変えない行動 |
|---|---|---|
| 社長 | 朝礼で一言言う。月1回、紙を1枚見る | 判断、電話、付き合い、全部そのまま |
| 配車担当 | LINEで配車表の下書きを受け取る（数ヶ月後） | 配車の判断、電話、紙の配車表 |
| 運転手 | **伝票を撮って送る（往復ごと）。夕方OKを押す** | 紙の伝票、紙の日報（当面）、電話、日当 |
| 事務 | 仕事が減る | ― |
| 元請け・監督 | なし | 全部 |
| 持込業者 | なし | 全部 |
| 処分場の受付 | 受入票をこちらに回す（または自社発行なら自動） | 受付の仕方 |

**変化は運転手の写真1枚に集約されている。** 導入の難しさは、この1動作をどう25人にやってもらうか、に還元される。それなら解ける。

---

## 3. 社長が本当に恐れていること（無料でも断る理由）

| 恐れ | 中身 | 設計での答え |
|---|---|---|
| 運転手が辞める | 「余計なこと増やすと、あいつら辞めるぞ」 | 増やすのは写真1枚。待機手当の原資ができ、公平になる。辞める理由ではなく残る理由 |
| 元請けに迷惑 | 「ハウスメーカーに変なこと頼めない」 | 元請けには何も頼まない。書式も条件もそのまま |
| 失敗して恥 | 「やってみてダメだったら、俺が言い出した手前…」 | 紙はそのまま残るので、いつでも戻れる。「30日で合わなければ終わり」を先に言う |
| 情報が外に出る | 「うちの単価や得意先を知られたくない」 | 個社データは外に出さない。同じ市で同業は取らない。書面で約束 |
| 分からないものに依存する | 「俺はITが分からん。止まったら困る」 | 社長は何も触らない。止まっても紙がある。担当者の顔と携帯番号を渡す |
| 若造に仕切られる | 「現場も知らんやつが」 | 現場に行く。朝に行く。業種の言葉で話す。知人の紹介という土台 |

無料は、この6つの恐れを一つも消さない。消すのは設計と振る舞い。

---

## 4. 大義名分（社長が「変える」を言える理由）

社長は「便利だから」では変えない。周りに「ITかぶれ」と見られたくない。
だから **外から来た理由** を渡す。すでに揃っている。

| 外圧 | 社長の言葉になる |
|---|---|
| 2024年問題（運転手の拘束時間の記録と上限） | 「法律で運転手の時間を記録しなきゃならんくなった」 |
| 電子帳簿保存法（紙の伝票も電子で保存する方向） | 「伝票を電子で残せって言われてる」 |
| インボイス | 「請求書の形が変わった」 |
| 盛土規制法・残土条例（受入の記録と届出） | 「穴の方も書類が厳しくなった」 |
| 産廃の電子マニフェストの流れ | 「マニフェストも電子になっていく」 |
| 大手ハウスメーカーの協力会社へのシステム入力要求 | 「元請けが入力しろって言ってきてる」 |

これらを社長に「理由」として渡す。社長は朝礼で「法律で記録が要るようになったから、伝票は写真で送れ」と言える。顔が立つ。

---

## 5. 運転手25人に「写真1枚」をやってもらう方法

| 手 | 中身 |
|---|---|
| 社長の一言 | 朝礼で30秒。「伝票、撮って送れ。紙はそのままでいい」。これが9割 |
| 職長・若手を一人、先に味方にする | 最初の1週間、その人の日報だけ自動で出し、本人に「今月の稼働」を見せる。「楽だぞ」と言ってもらう |
| 待機手当 | 待機料を元請けに請求できるようになったら、一部を手当にする。「写真を送ると手当が増える」 |
| 責めない | 送り忘れは、夕方にこちらがLINEで聞く。叱るのは誰でもない。「催促はこっちの仕事」 |
| ベテランの逃げ道 | **伝票ボックス。** 夕方、車庫の箱に伝票を入れるだけ。こちらが撮る。行動変化ゼロ |
| 2週間で諦めない | 1週目60%、2週目80%、4週目95%が普通。残り5%は伝票ボックス |

## 6. 順番（しきたりに触れない順）

| 順 | やること | 行動変化 |
|---|---|---|
| 1 | 自社処分場の受入票と、過去3ヶ月の紙を預かって集計 | ゼロ。社長が紙を渡すだけ |
| 2 | 月末の請求書を、紙の伝票から作る | ゼロ。事務が楽になるだけ |
| 3 | 伝票ボックスを車庫に置く | ほぼゼロ。箱に入れる |
| 4 | 写真で送る運転手を増やす（職長から） | 写真1枚 |
| 5 | 夕方の自動日報とOK | タップ1回 |
| 6 | 位置情報で待機の自動化（デジタコのある車から） | ゼロ（機械から取る） |
| 7 | 配車の聞き取りと入力 | 配車担当がLINEを見る |

**行動変化ゼロの段階で、3枚の一覧の粗い版を出す。** 社長が「初めて見た」と言った後に、写真を頼む。順番が逆だと断られる。

---

## 7. しきたりは堀になる

- この業界がSaaSを入れない理由（紙、口頭、現場主義）は、こちらが入った後、競合も入れない理由になる。
- 「紙のまま、写真だけ」「配車に触らない」「現場に来る」を守った会社は、乗り換えられない。乗り換え先は「入力しろ」と言うから。
- しきたりを尊重する姿勢そのものが、紹介の理由になる。「あいつは現場を分かってる」。

---

## 8. 一言で

しきたりは突破しない。横に層を足す。
変えるのは運転手の写真1枚だけで、それすら伝票ボックスで逃げ道を作る。
社長には「法律で記録が要る」という大義名分を渡し、朝礼の一言で動かす。
行動変化ゼロの段階で数字を見せてから、写真を頼む。
