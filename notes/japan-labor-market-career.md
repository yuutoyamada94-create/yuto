# 日本のキャリア・労働市場はどうなるか（2026〜2030）

作成日: 2026-10-02
前提: `ai-organization-2027-market.md` の全体地図を踏まえ、日本固有の制度・人口動態を掛け合わせる。

---

## 0. 結論を先に

日本では「大量失業」は起きない。代わりに **「静かな構造転換」** が起きる。

- 失業率は低いまま。労働人口の減少（年50万人規模）がAIによる置換を吸収する。
- しかし中身は激変する。**事務系ホワイトカラーの大余り、現場・技能職の大不足** というミスマッチが拡大する。
- 解雇規制と新卒一括採用の制度があるため、調整は「解雇」ではなく **「採用停止 → 自然減 → 早期退職」** で進む。
- その結果、痛みは **若年層（新卒）と非正規** に集中する。就職氷河期の再来を「AI氷河期」として迎えるリスクがある。
- 既存大企業は「安全だが停滞」、AIネイティブ企業は「高リスクだが高報酬」に分かれ、キャリアの二極化が進む。

## 2. 日本固有の3つの力がぶつかる

```
       AIによる「実行」の置換
              ↓
  ┌───────────────────────────┐
  │   メンバーシップ型雇用 × 解雇規制   │ ← 制度の硬直性
  │   年功賃金 × 新卒一括採用          │
  └───────────────────────────┘
              ↑
       人口減少による人手不足
```

### 2.1 AIの置換圧力（グローバル共通）
事務、経理、翻訳、下流SE、コールセンター、ジュニアコンサル、士業の補助業務、広告運用、社内調整役としての中間管理職。

### 2.2 人口減少（日本固有のクッション）
働き手が毎年減るため、AIが置換した分の一部は「そもそも埋められなかった穴」を埋めるだけ。マクロの失業率は上がりにくい。
ただし減るのは「人」であり、減る職種と置換される職種は一致しない。現場は足りないまま、事務は余る。

### 2.3 制度の硬直性（日本固有の調整経路）
- **解雇規制**: 整理解雇の4要件が厳しく、「AIで不要になった」は解雇理由にならない。2024年の自民党総裁選で見直し論が出たが、制度変更は遅い。
- **メンバーシップ型**: 職務ではなく「人」を雇うため、仕事が消えても人は残る。社内失業（仕事のない正社員）が増える。
- **年功賃金**: 高コストの中高年が、AIでできる仕事を担い続ける構造。企業は耐えられなくなる。
- **新卒一括採用**: 「ポテンシャル採用して社内で育てる」が前提。ジュニアの仕事が消えると育成の起点が失われる。

→ 調整経路は「解雇」ではなく **「新卒を絞る」「非正規を切る」「早期退職を募る」「役職定年を早める」** になる。痛みは入口と周縁に集中する。

## 3. 時間軸シナリオ

### Phase A: 2026〜2027 「静かな採用凍結」
- 事務系・総合職の新卒採用が絞られる。「量から質へ」の名目で少数精鋭化。
- IT・AI人材は争奪戦。同じ「大卒」で初任給と求人倍率が二極化。
- 非正規の事務・コールセンターから置換が始まる（契約更新停止）。
- 早期退職募集が40代に下りてくる。
- 企業は「AIで人は減らさない」と言い続ける。

### Phase B: 2027〜2029 「総合職の意味の消失」
- 「なんでもやる総合職」の価値が崩れる。企業は役割を「判断・責任・関係を担う少数の人間」と「現場」に二分し、間をAIで埋める。
- 中間管理職（調整役）が最も余る。
- 新卒の「経験の階段」が壊れる。ジュニアの仕事がないので育てられず、企業は「即戦力の中途」を求めるが、即戦力はどこでも育っていない。供給の断絶。
- 現場・技能職（建設、設備、電気、介護、物流）の賃金が相対的に上がる。「大卒事務より高卒技能のほうが稼げる」逆転が可視化される。
- 副業・フリーランスでAIを使って個人が稼ぐ層が目立ち始める。

### Phase C: 2029〜2030以降 「制度の限界と改革」
- 社内失業と年功賃金の負担で、中堅企業からメンバーシップ型が財務的に維持できなくなる。
- 解雇の金銭解決ルール、ジョブ型への移行が現実の政策課題になる。
- 「AI氷河期世代」（2026〜2029卒）の問題が社会問題化する。
- 労働分配率の低下、AI課税・再分配の議論が本格化。

## 4. 職種別の見通し

### 4.1 縮む職種（置換の順番）
1. 一般事務、営業事務、データ入力（すでに半減）
2. コールセンター、カスタマーサポート
3. 経理、人事労務の定型業務
4. 翻訳、ライティング、デザイン制作の下流
5. 下流SE、SES、テスト
6. ジュニアコンサル、リサーチ、アナリスト補助
7. 士業（税理士、社労士、行政書士）の補助業務
8. 広告運用、Webマーケの実行部分
9. 社内調整型の中間管理職

### 4.2 残る・伸びる職種

| 領域 | 具体例 | 理由 | 持続性 |
|---|---|---|---|
| 現場技能（有資格） | 施工管理、電気工事、設備、配管 | 物理世界、資格、人手不足 | 中長期 |
| 医療・介護 | 看護、介護福祉士、理学療法 | 身体接触、信頼、制度 | 長期 |
| 物流・インフラ | ドライバー、保守、電力 | 物理、ただし自動化は進む | 中期 |
| 大型法人営業 | 関係構築、交渉、責任 | 信頼は人間が売る | 長期 |
| 事業オーナー・経営 | P&L責任、意思決定 | 責任はAIが取れない | 長期 |
| AIを使って事業を回す人 | AIネイティブ企業の少数精鋭 | レバレッジ側 | 長期 |
| 士業の「署名・責任」部分 | 税理士の署名、弁護士の代理 | 法的責任、独占業務 | 中長期（制度次第） |
| 対面教育・保育 | 人間が人間を育てる | 信頼、身体性 | 長期 |
| 一次産業・食 | 農業、水産、料理人 | 物理、人間性のプレミアム | 長期 |

### 4.3 「資格」の価値が日本では特に上がる
独占業務のある国家資格（士業、施工管理技士、電気工事士、看護師、介護福祉士、宅建など）は、AIが実行できても **法的に人間の署名・責任が必要** な限り、参入障壁として機能する。日本は資格制度が強いため、この効果が大きい。ただし「資格があれば安泰」ではなく、「資格×AI活用」で1人あたりの処理量が10倍になり、同業者の数は減る。

## 5. 世代別のキャリア戦略

### 5.1 20代（これから入る・入ったばかり）
最も影響が大きい世代。「新卒カードで大手の総合職に入って育ててもらう」モデルが機能しなくなる。
- **事務系総合職を目指さない**。入れても育成の階段がない。
- 選択肢は3つ。
  1. **現場・技能＋資格**: 建設、設備、医療、介護。10年後に稼げている確率が最も高い。
  2. **AIレバレッジ型ビルダー**: AIを使って自分で作る・売る・回す。実績で評価される小規模企業・スタートアップへ。
  3. **責任を早く引き受ける**: 大企業に入るなら、早くP&Lや顧客を持つ部署へ。調整役の中間層は避ける。
- 「新卒」というシグナルより **「何を作ったか・何を売ったか」** のポートフォリオが効く。
- 語学の壁が消えるので、日本市場に閉じない選択肢を持つ。

### 5.2 30〜40代（中堅の事務系・企画系）
「静かな陳腐化」のリスクが最も高い。会社にいる限り解雇はされないが、仕事が消え、賃金は上がらず、早期退職の対象になる。
- **責任のある役割へ移動する**: 顧客を持つ、P&Lを持つ、意思決定者になる。
- **社内でAIワークフローを設計する側に回る**: 置換される側から置換する側へ。過渡期の5年間は最も需要がある。
- **副業で市場価値をテストする**: 社内評価と市場価値の乖離を早く知る。
- **「この会社でしか通用しない調整力」を資産と思わない**。

### 5.3 50代
年功賃金の頂点にいて、AIでできる仕事をしている層は早期退職の最初の対象。
- **関係と経験を「助言」に変換する**: 顧問、アドバイザー、地域企業の経営支援。
- **現場・物理・地域へ**: 人手不足の現場は中高年を受け入れる。
- **退職金・資産でAI組織を持つ**: 小規模事業を人間1人＋AIで回す選択肢が現実になる。

### 5.4 全世代に共通
- 単一の雇用への依存を下げる。
- **信頼と固有の人間関係** を長期資産として蓄積する。これはAIで複製できない。
- 「実行」を売らず、「判断・責任・関係」を売る。
- 日本では **資格** が参入障壁として効く。取れるなら取る。

## 6. 企業側から見た労働市場

- **既存大企業**: 「安全だが停滞」。AI導入を「人を減らさない前提」で進めるため生産性向上が遅く、賃金が上がりにくい。社内失業を抱える。
- **AIネイティブ企業**: 「高リスクだが高報酬」。少数精鋭に高い給与を払い、残りはAI。
- **中堅企業**: 最も苦しい。年功賃金と社内失業の負担に耐えられず、改革か淘汰か。
- **中小・現場企業**: 人手不足が深刻で、AIは「人を減らす」ではなく「穴を埋める」手段。事務をAI化し、人は現場へ。

企業の採用行動は「新卒一括 → 少数の新卒＋即戦力中途＋AI」に変わる。即戦力の供給源が枯れるため、「育成できる企業」が長期的に優位になるという逆説がある。

## 7. 政策・制度の論点（観測対象）

| 論点 | 状況 | 影響 |
|---|---|---|
| 解雇の金銭解決 | 2024年総裁選で争点化、制度化は未 | 導入されれば調整が「解雇」側に移り、若年層の痛みが減り中高年の痛みが増える |
| ジョブ型雇用 | 大企業で部分導入 | 進めば職務単位の置換が可視化される |
| リスキリング支援 | 補助金はあるが、需要側（現場・技能）とのミスマッチ | 事務→ITへの転換は難しく、事務→現場への転換は心理的抵抗 |
| 副業解禁 | 進行中 | 個人がAIで稼ぐ経路が開く |
| 外国人労働 | 現場の穴埋め | 現場賃金の上昇を抑える方向 |
| AI課税・再分配 | 議論前 | 2029年以降に本格化 |
