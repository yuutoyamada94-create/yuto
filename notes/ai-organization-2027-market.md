# 2027年「オーガナイゼーション」レベル到達を前提とした未来市場の解像度

作成日: 2026-10-02
目的: AIが「組織を丸ごと運営できる」水準に達した世界で、市場・企業・個人がどう変わるかを構造的に整理し、観測指標まで落とす。

---

## 0. 現在地と前提の確認

### 0.1 「オーガナイゼーション」とは何か
OpenAIが2024年7月に社内共有した5段階フレームの最上位。

| Lv | 名称 | 内容 | 2026年10月時点 |
|---|---|---|---|
| 1 | Chatbots | 会話 | 完了 |
| 2 | Reasoners | 博士級の問題解決 | 完了 |
| 3 | Agents | 数日単位の自律行動 | 普及期 |
| 4 | Innovators | 発明・新規知見の創出 | 萌芽 |
| 5 | Organizations | 組織を丸ごと運営 | 限定ドメインで実証段階 |

### 0.2 2027年到達は「楽観寄りだが非現実的ではない」
- METRの時間地平（AIが自律完遂できるタスク長）は2024年以降およそ105日で倍増。2026年3月時点で16時間。この曲線が続けば2027年末には「週単位」の自律タスクに届く。
- AnthropicのProject Vend Phase2では、店舗運営エージェントの上に「AI CEO」層を置くことで黒字化。「AIがAIを監督する多層組織」が小規模ながら実証された。
- 一方でAI 2027の著者Kokotajloは2026年時点で「2027年末までには多分起きない、2030年までには多分起きる」と中央値を2028年に修正。

→ 実務上の読み: **2027年は「限定ドメインでAIが事業を自律運営できる」ことがフロンティアで確定する年**。全産業に浸透する年ではない。

### 0.3 最重要の区別: 「技術の到達」と「市場の浸透」は別
- 2026年の企業調査: 97%が「エージェントを導入した」と答える一方、全社規模でスケールしているのは23%。
- 日本: 生成AI活用は3〜4割、AIエージェント導入は3%。大企業と中小の格差は30ポイント超。
- 歴史的に、汎用技術がフロンティアから経済統計に現れるまで3〜7年のラグがある。

ただし今回は2つの点で過去と違う。
1. 導入コストがほぼソフトウェア配布コスト（物理設備不要）。
2. 「できることが確定する」だけで資本・人材・採用計画が先回りして動く（新卒採用の縮小はすでに始まっている）。

## 1. 本質: 何が根本的に変わるのか

### 1.1 企業の最小単位が変わる
これまで「事業」は人を複数集めないと成立しなかった。L5では「人間1人＋AI組織」で事業が成立する。
事業の立ち上げコストが、資本と組織構築から「意思と検証」に変わる。

### 1.2 企業の境界が変わる（取引コスト理論の再適用）
企業は「内部化コスト < 市場取引コスト」のときに大きくなる。AIは両方を激減させる。結果は二極化する。
- 内部化が極端に安い → 巨大プラットフォームが何でも内製する。
- 市場取引が極端に安い → 超小規模企業が無数に生まれ、API経由でつながる。
中間規模（数百〜数千人の「普通の会社」）が最も構造的に不利になる。

### 1.3 労働の価値が分解される
仕事を「実行」「判断」「責任」「関係」「資本」に分解すると、AIが奪うのは主に「実行」。
実行の価格がゼロに近づくと、残り4つの相対価値が跳ね上がる。

### 1.4 「組織能力」そのものがコモディティ化する
採用・育成・プロセス設計・マネジメントといった、これまで企業の競争力だったものがAPIで買えるようになる。
差別化の源泉は「組織の中」から「組織が持つ希少資源」へ移動する。

## 2. 時間軸シナリオ（2026〜2030）

### Phase A: 2026後半〜2027 「部門単位の置換」
- 数日〜1週間の自律タスクが実用化。
- ソフトウェア開発、カスタマーサポート、調査分析、経理・総務のバックオフィスで「部門ごとAI化」が進む。
- AIネイティブ企業（従業員10人以下、売上数十億円）がメディアで目立ち始める。
- SaaSの「席数課金」が崩れ始める。
- 新卒・ジュニア採用の縮小が統計に出る（米国のソフトウェア・コンサル・会計から）。

### Phase B: 2027〜2028 「限定ドメインでの自律経営」
- EC、SaaS、コンテンツ、デジタルマーケティング、一部の資産運用など、デジタル完結の事業でAIが「運営」する。
- 人間の役割は「オーナー・監督者・責任者」に集約。
- 「1人ユニコーン」が現実の事例として出る。
- 規制・責任問題が顕在化（AIが締結した契約の有効性、損害の責任主体）。
- AIエージェント向けの保険・監査・ガバナンス市場が立ち上がる。

### Phase C: 2028〜2030 「拡散と構造変化」
- 医療、金融、法務など規制産業への浸透。
- 労働市場の構造変化がマクロ統計に現れる。
- 政策論争（AI課税、UBI、労働時間）が本格化。
- 物理世界（ロボティクス）が次のフロンティアに。

### ボトルネック（遅延要因）
1. 物理世界: ロボティクスはソフトウェアより数年遅れる。
2. 規制と責任: 「誰が責任を取るか」が解決しないと規制産業は動かない。
3. 計算資源と電力: フロンティアの推論コストと電力供給。
4. 信頼性: Vend Phase1の失敗のように、長時間自律の信頼性は監督層が必須。
5. 人間側の変化速度: 組織・制度・心理は技術より遅い。

## 3. 市場構造の変化

### 3.1 レイヤー構造
```
┌─────────────────────────────────────┐
│ 物理・信頼・関係層（人間が残る領域）        │  物理資産、ライセンス、ブランド、関係
├─────────────────────────────────────┤
│ 垂直AIネイティブ事業層                     │  業界特化で自律運営する事業体
├─────────────────────────────────────┤
│ エージェント基盤・オーケストレーション層     │  「組織OS」。監督、記憶、権限、監査
├─────────────────────────────────────┤
│ フロンティアモデル層                       │  数社の寡占、API価格競争で利益率圧縮
├─────────────────────────────────────┤
│ 計算資源・電力層                          │  最大の資本集約、国家戦略レベル
└─────────────────────────────────────┘
```
利益が集まるのは上下両端（計算資源と物理・信頼）と、組織OS層。中間のモデル層は競争激化で利益率が圧縮される。

### 3.2 コモディティ化するもの / 希少化するもの

| コモディティ化（価格→0） | 希少化（価格↑） |
|---|---|
| 汎用知的労働全般 | 固有データとフィードバックループ |
| ソフトウェア開発 | 物理的制約のある資産（土地、電力、工場、インフラ） |
| コンテンツ制作、翻訳 | 規制上のライセンス、許認可 |
| 分析、調査、レポート | 信頼、ブランド、人間関係 |
| カスタマーサポート | 「何が欲しいか」を決める意思 |
| 一般管理業務 | 責任を引き受ける能力 |
| 組織をつくる能力そのもの | 人間の注意（attention） |
| 専門知識の「保有」 | 検証・監査・署名の能力 |

### 3.3 価格とマージンの再編
- **SaaS**: 席数課金が消え、成果報酬・従量・エージェント単位課金へ。「ユーザーがAIなら席はいらない」。
- **プロフェッショナルサービス**（コンサル、法律、会計、広告代理店）: 時間売りモデルが崩壊。成果と責任を売る形へ。
- **ジェボンズのパラドックス**の切り分けが重要:
  - 価格低下で需要が拡大する領域（ソフトウェア、カスタム製品、個別最適化されたサービス）
  - 需要が有限で縮む領域（定型レポート、翻訳、一般事務）
  同じ「AIで安くなる」でも市場規模は逆方向に動く。

### 3.4 日本固有の条件
- **人手不足が導入圧力になる**: 労働人口減少がAI置換の社会的痛みを緩和し、導入を正当化する。
- **大企業と中小の格差**: 中小の問題は「導入しない」ことではなく「AIネイティブ競合に食われる」こと。
- **解雇規制**: 置換は解雇ではなく「採用停止 → 自然減」で進む。影響は新卒市場に最初に、最も強く出る。
- **言語の壁の消滅**: これまで国内市場を守っていた日本語の壁が消え、海外AIネイティブ企業が直接参入できる。
- **円安と電力**: 計算資源の調達コストが構造的に不利。
- **現場・物理の強さ**: 製造、建設、介護、飲食などは当面残り、相対的に価値が上がる。

## 4. 企業の在り方

### 4.1 企業形態の分化（4類型）

| 類型 | 特徴 | 勝ち筋 | リスク |
|---|---|---|---|
| ハイパースケール型 | 計算資源・データ・資本を持ち、AIを内部化 | 規模とデータの複利 | 規制、独占批判 |
| AIネイティブ小規模型 | 人間数人＋AI組織。高速に生まれニッチを取る | 速さ、低コスト、試行回数 | 参入障壁が低く模倣される |
| 物理・関係アンカー型 | 物理資産、ライセンス、地域、信頼を持つ既存企業がAIを乗せる | 希少資源×AIの掛け算 | 内部の変革速度 |
| 取り残され型 | 旧来組織のままAIを部分導入 | なし | コスト構造で負ける |

既存企業の問いは「自分はどの類型に向かうのか」。中間規模で「普通の会社」のままでいることが最も危険。

### 4.2 組織設計の変化
- **ピラミッドからハブ&スポークへ**: 少数の人間が多数のAIエージェントを監督する。
- **管理職の役割転換**: 人の管理 → エージェントの設計・評価・監査。
- **ジュニア層の消失問題**: 実行層が消えると育成パイプラインが切れる。5〜10年後の中堅人材が供給されない。これは企業単体では解決できない構造問題。
- **意思決定が人間側のボトルネックに**: AIは秒で提案するが、人間の承認は日単位。承認構造の再設計（権限委譲の粒度、事後監査への移行）が競争力になる。
- **組織の記憶と文脈がデータ資産に**: 暗黙知、判断基準、顧客履歴をAIが使える形にしておくこと（コンテキスト設計）が差別化要因。

### 4.3 競争優位の源泉の移動

| 弱くなる | 強くなる |
|---|---|
| プロセスの優秀さ | 固有データとフィードバックループ |
| 人材の質と量 | 流通・顧客接点の保有 |
| 専門知識の蓄積 | 試行回数（探索の速さ） |
| 組織力・実行力 | 信頼と責任（AI生成物の「署名者」としての企業） |

### 4.4 経営者が今答えるべき問い
1. 自社の価値のうち「組織能力」に依存している部分はどこか。それはコモディティ化する。
2. 自社が持つ、AIでは複製できない希少資源は何か。
3. AIネイティブの競合が明日、自社の最も利益率の高い事業に参入したら、何で勝つか。
4. 従業員の「置換」ではなく「移動」の計画はあるか。どこへ移すか。
5. 承認・意思決定の構造を、AIの速度に合わせて再設計しているか。

## 5. 個人の在り方

### 5.1 労働市場の分解
「実行者」としての価値は急落する。特に新卒・ジュニアの汎用知的労働が最初に、最も強く影響を受ける。

残る、または伸びる領域:

| 領域 | 内容 | 持続性 |
|---|---|---|
| 意思と責任 | オーナー、意思決定者、最終責任者 | 長期 |
| 需要の定義 | 「何が欲しいか」「何が問題か」を決める | 長期 |
| 信頼と関係 | 顧客、コミュニティ、政治、交渉 | 長期 |
| 物理世界 | 職人、医療現場、建設、介護、農業 | 中期（ロボティクス次第） |
| AIの監督・検証・設計 | エージェント設計、評価、監査 | 過渡期（やがてAIが担う） |
| 人間性そのもの | 対面、体験、文化、芸術 | 長期（「人間である」ことのプレミアム） |

### 5.2 個人の戦略
1. **「雇われる」から「所有する」へ**: AI組織を使えるなら、個人が事業体になれる。労働収入の比重を下げ、事業・資産収入の比重を上げる。
2. **レバレッジを1つ持つ**: 資本、オーディエンス、固有データ、ライセンス、物理資産のいずれか。AIは「掛け算の相手」であって、ゼロに掛けてもゼロ。
3. **問いを立てる力と審美眼**: 答えはAIが出す。「何を問うか」「どれが良いか」を決める力が希少になる。
4. **責任を引き受ける力**: AIは責任を取れない。「自分の名前で署名できる」ことが価値になる。
5. **信頼と関係の蓄積**: AIで代替できない唯一の長期資産。時間をかけてしか作れない。
6. **学習の仕方を変える**: 専門性の「保有」の価値は下がる。「AIを使って即座に深く入る」力と、「AIが到達しにくい領域」の専門性に絞る。
7. **複数の収入源**: 単一の雇用への依存を減らす。

### 5.3 社会的な側面
- **所得分配**: 労働分配率が下がり、資本・AI所有者に集中する。政策論争（AI課税、UBI）が2028年以降に本格化。
- **仕事の意味**: アイデンティティと社会的つながりを「仕事」以外に持つ必要が出てくる。
- **教育**: 既存のカリキュラム（知識の習得と実行の訓練）が陳腐化。「判断」「責任」「関係」を教える教育への転換が遅れる。

## 7. 不確実性と反論

| 論点 | 内容 | 影響 |
|---|---|---|
| タイムライン遅延 | Kokotajloの中央値は2028。2030までずれ込む可能性 | Phase B/Cが1〜3年後ろ倒し |
| 信頼性 | 長時間自律の失敗（Vend Phase1）。監督層のコストが残る | 完全自律ではなく「人間監督付き」が長く続く |
| 規制・責任 | AIが法人として契約・責任を負えるか未解決 | 規制産業への浸透が遅れる |
| 需要側 | ジェボンズ（需要拡大）か飽和か。領域ごとに逆方向 | 市場規模予測が領域で大きく異なる |
| 社会的抵抗 | 労働組合、政治、世論 | 規制強化で速度が落ちる |
| 計算資源 | 電力・チップの制約で推論コストが下がりきらない | 普及が資本力のある企業に偏る |

反論として最も強いのは「AIは実行はできるが、責任と信頼を引き受けられない。そして経済の多くは責任と信頼の上に成り立っている」。これが正しければ、変化は「置換」ではなく「人間の役割の再定義」で止まる。

## 9. 次に解像度を上げる方向

この整理は「全体地図」。次は以下のどれかに絞ると具体的になる。
1. **業界を絞る**: どの業界の、どのプロセスから変わるか。
