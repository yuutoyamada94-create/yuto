## 2. この会社の読み解き

### 2.1 何屋か
ダンプの運送会社であり、同時に **処分場の持ち主** 。運ぶだけでなく「受け入れる」側でもある。
処分場は物理資産で、他のダンプ会社・工務店・解体業者が土を持ち込む。つまりこの会社は **地域の現場企業が集まるハブ** 。
→ 1社目としての価値が高い。受入の客がそのまま次の顧客候補になる。

### 2.2 日々の事務の中身（推定）
| 業務 | 内容 | 負荷 |
|---|---|---|
| 配車の受付 | ハウスメーカー・工務店・解体業者から電話で依頼。現場、日時、台数、土質・品目、処分先を聞き取り、配車表へ | 電話が集中する。夜勤があるので夜も鳴る |
| 運転手の日報 | 車番、現場、往復回数、処分先、伝票 | 紙の可能性が高い。30名分 |
| 受入の伝票 | 処分場で受け入れた土の伝票、持込業者ごとの集計 | 日次 |
| 産廃マニフェスト | 紙または電子（JWNET）。入力と照合 | 法定。ミスできない |
| 請求 | 月末に得意先別・現場別。ハウスメーカーは支店ごと、書式指定あり | 伝票の束を月末にまとめる |
| 支払い | 処分先、燃料、修理、リース | 月次 |
| 運転手の拘束時間 | 2024年問題で時間外上限。日報から集計 | 運行管理の資料。手でやると重い |
| 採用 | 運転手を常時募集。事務も募集 | 応募対応と面接設定 |

### 2.3 痛みの仮説（順番）
1. **事務の人が足りない。** 「事務スタッフ 要相談」で募集している。給与を書けていないのは、相場も人物像も決めかねている状態。ここが入口。
2. **電話と配車が特定の人に集中している。** 夜間の資材置場の問い合わせが個人の携帯に公開されている。夜も誰かの携帯が鳴る会社。
3. **運転手の採用。** 日給13,000〜15,000円は首都圏ダンプの相場付近。差別化しにくく、採れにくい。
4. **月末の伝票と請求の束。** 現場数×車両数×日数。ハウスメーカーの書式対応。
5. **2024年問題の時間管理。** 運転手の拘束時間を日報から出す必要がある。

### 2.4 価値観との接続
社長の言葉は「お客様・会社・従業員・家族・従業員の家族」「挨拶」。
→ 刺さる言い方:
- 「運転手さんが、現場から事務所に電話しなくて済むようにします」
- 「夜中の電話を、人が取らなくていい会社にします」
- 「事務の人を一人、24時間置きます。採れるまで待たなくていいです」
- 「挨拶を大切にする会社なので、電話の一声目を落とさないようにします」

## 6. 電話の第一声（手紙の3日後）

「松山社長はいらっしゃいますか。〇日にお手紙をお送りした〇〇です。事務スタッフを募集されている件で、15分だけお時間いただけませんか。」

社長不在なら: 「配車をご担当の方はいらっしゃいますか」と聞き、同じ一言。

言わない言葉: AI、DX、システム、効率化、ツール。

## 7. 最初の15分の質問（この会社向け）

1. 「今、一番困っているのは、運転手さんの採用ですか、事務の人ですか、電話の多さですか」
2. 「配車の電話は、今どなたが取っていますか。夜勤の日は？」
3. 「月末の請求、伝票を集めてから何日かかっていますか。ハウスメーカーさんの書式は何種類ありますか」
4. 「運転手さんの日報は紙ですか。拘束時間の集計はどうされていますか」

提案の一言:
「募集中の事務スタッフの代わりに、電話と配車の受付、日報、伝票、請求書までやる事務員を、30日タダで置かせてください。配車の判断は今まで通りです。」

## 10. 30日無料の設計（この会社）

| 日 | やること |
|---|---|
| 1〜3日 | 電話転送とLINE窓口。配車担当と「聞き取り項目」を決める。運転手に伝票写真の送り方を説明（朝礼で5分） |
| 7日 | 「初週、電話◯件、夜間◯件を取りこぼしませんでした」 |
| 14日 | 日報集計を配車担当に見せる。拘束時間の一覧を初めて出す |
| 25〜31日 | 月末請求を事務員が作り、社長が確認だけ。ここが山場 |
| 31日 | 月次報告1枚。「続けますか」 |

転換の鍵: **月末の請求を一度、事務員が回しきること。** これを体験すると戻れない。

## 11. この会社の後ろにある網

- 処分場に土を持ち込む業者（他のダンプ会社、解体、工務店）が、そのまま次の顧客候補。社長に「同じ悩みの持込業者さんがいたら」と託せる。
- ハウスメーカーの下請け仲間（基礎、外構、解体）も同じ現場で顔を合わせている。
- 鶴見・緑・青葉で「残土・産廃」は1社しか取らないと約束する。
