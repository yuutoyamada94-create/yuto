# 今後の価値の源泉と、私が今起業するなら何をするか

作成日: 2026-10-02
前提: これまでの3本のノートの続き。ここは分析ではなく「立場を取る」ノート。

---

## 1. 価値の源泉はどこへ移るか

### 1.1 原理
価値 = 希少性 × 需要。
AIがやっているのは **「増やせるもの」の希少性を全部ゼロにすること** 。知識、実行、制作、分析、コード、文章、設計。これらは複製コストがゼロになる。
だから価値は **「AIが増やせないもの」** に移る。それだけ。

### 1.2 AIが増やせないもの（5つ）

| 順位 | 源泉 | 中身 | なぜAIが増やせないか |
|---|---|---|---|
| 1 | 需要の所在 | 顧客、信頼、流通、「この人から買う」という関係 | 信頼は時間でしか積めない。供給が無限になると需要側が全てを決める |
| 2 | 責任の引受 | 法的署名、保証、信用、「失敗したら自分が被る」立場 | AIは法的主体になれない。責任は人間か法人にしか置けない |
| 3 | 物理 | 土地、電力、設備、身体、現場、立地 | 原子は複製できない。ロボティクスは数年遅れる |
| 4 | 固有データ | 現実世界の記録、フィードバックループ、公開されていない文脈 | AIは学習データの外を知らない。現場で起きたことは現場にしかない |
| 5 | 判断と意味 | 何を欲しいか、何が良いか、何を切り捨てるかを決める力 | 答えは無限に出る。問いと選択は人間の側に残る |

### 1.3 一言で
**価値は「作る側」から「欲しがる側を持つ側」へ移る。**
作れる人は無限になる。「誰が買うかを知っていて、その人に売れる」人が全てを持つ。

### 1.4 死ぬ価値（念のため）
- 知識の保有（検索と推論で代替）
- 実行の速さ（AIが速い）
- 「AIで速くなる」を売る商売（実行の中間層。価格がゼロに向かう）
- 情報の非対称性で稼ぐ商売（仲介、代理店、コンサルの大半）

## 2. 私が今、起業するなら

### 2.1 選定基準
1. 価値の源泉（上の5つ）のうち複数を同時に押さえる
2. AIが強くなるほど **強くなる** 事業（AIが強くなると弱くなる事業は論外）
3. 日本で、今、小さく始められて、複利が効く
4. 「実行を売らない」

### 2.2 答え: 後継者不在の現場産業の中小企業を承継し、AI組織で運営する

#### 何をするか
地方の、現場を持つ中小企業（設備工事、管工事、電気工事、運送、介護、食品製造、建材など）で、後継者がいない黒字企業を承継し、バックオフィス・営業管理・見積・調達・採用をAI組織で回す。現場の職人と顧客関係はそのまま残す。
これを1社で終わらせず、同業で複数社まとめる。

#### なぜこれか
**裁定（アービトラージ）がある。**
- これらの企業は「実行が高い世界」の経済で値付けされている。人が足りず、事務が重く、社長が全部やっていて、利益率が低く見える。だから安い。承継価格がゼロに近いことすらある。
- しかし持っているのは「AIが増やせないもの」そのもの。顧客との関係、地域の信頼、許認可、設備、現場の人、立地。
- AIで事務と営業管理を回すと、原価構造が変わる。「実行が無料の世界」で運営すると、同じ資産から出る利益が別物になる。
→ **「実行が高い世界の価格」で「実行が無料の世界の資産」を買う。** これが裁定。

**日本固有の巨大な供給がある。**
- 後継者未定の中小企業は約127万社（経産省、2025年問題）。黒字廃業が年数万社規模。
- 社長の平均年齢は60代後半。売り手は増え続け、買い手は少ない。
- 事業承継・引継ぎ支援センター、M&Aプラットフォーム、承継補助金など、制度は整っている。

**価値の源泉を4つ同時に押さえる。**
1. 需要の所在: 既存顧客と地域の信頼を買う
2. 責任の引受: 自分がオーナーとして責任を取る（これが承継の本質）
3. 物理: 現場、設備、許認可、人
4. 固有データ: 現場の見積、施工記録、顧客履歴。これをAIが使える形にした瞬間、次の承継の価値が上がる

**AIが強くなるほど強くなる。**
AIが進めば進むほど、承継した会社のバックオフィスは安くなり、現場と顧客関係の相対価値は上がる。追い風しか吹かない。

**複利が効く。**
1社目で作った「この業種のAI組織OS」（見積、工程、調達、採用、経理の自動化と、その業種固有の判断ルール）は2社目にそのまま乗る。業種内で集めるほど、データも、仕入れ交渉力も、採用力も複利で増える。

**社会的正当性がある。**
v2の世界では信頼が全て。「廃業する会社を残し、雇用と地域の供給を守っている」事業は、信頼を得やすい。

#### なぜ他ではないか

| 候補 | 捨てた理由 |
|---|---|
| 垂直AI SaaS（士業向け、不動産向けなど） | 売っているのが「実行の効率化」。価格はゼロに向かう。モデル各社に食われる |
| AIエージェントの監査・保険 | 価値の源泉としては正しいが、規制と大資本（保険会社）の領域。小さく始めて勝てない |
| AI導入コンサル・ワークフロー構築 | 稼げるが賞味期限2〜4年。資金源にはなるが終着点にならない |
| コミュニティ・対面事業 | 信頼は積めるが複利が効かない。ライフスタイル事業としては良い |
| 固有データの生成（センサー、現場記録） | 方向は正しいが、データを「誰に売るか」が弱い。承継事業の中に組み込む方が強い |
| 1人事業体（情報発信、D2C） | v2の典型だが、個人の信頼に依存し、売却も承継もできない |

#### どう始めるか（最初の24ヶ月）

| 時期 | やること | 目的 |
|---|---|---|
| 0〜3ヶ月 | 業種を1つ、地域を1つに絞る。設備工事か運送か介護。同業10社の社長に会う | 現場の実態と「社長が抱えている事務」を知る |
| 3〜9ヶ月 | 5社に「バックオフィスをAIで肩代わりする」サービスを安く提供する | 業種のワークフローを学び、信頼を作り、資金を得る。ここが「過渡期の仕事」を資金源に使う部分 |
| 9〜15ヶ月 | その中で後継者不在の1社を承継する（支援センター、M&Aプラットフォーム経由も並行） | 1社目。自分がオーナーになり責任を取る |
| 15〜24ヶ月 | 1社目のAI組織OSを完成させ、利益率を上げる。2社目の承継に入る | 複利の起点 |

承継を最初にやらない理由: 業種を知らずに買うと、現場と顧客に信頼されない。先に「役に立つ外部の人」になってから買う。

#### 最大のリスクと対処

| リスク | 対処 |
|---|---|
| 現場の人がついてこない | 承継後1年は現場を一切変えない。変えるのは社長の机の上だけ |
| 業種を間違える | 「現場が重く、事務も重く、許認可があり、顧客が地域に固定されている」業種を選ぶ。IT化で消える業種は避ける |
| 自分が「実行」に埋もれる | AI組織OSが完成するまで2社目に手を出さない |
| 承継の資金 | 初期は小さい会社（売上1〜3億）。承継補助金、日本政策金融公庫、売り手との分割 |
| 人の管理が重い | 承継する会社は「現場が自走している」会社に限る。社長が営業と事務に忙殺されている会社が狙い目 |

## 3. この答えの構造（応用のために）

私の答えを一般化すると、v2の起業は次の形になる。

```
「実行が高い世界」で安く値付けされている
「AIが増やせない資産」（顧客・信頼・物理・許認可・データ）を手に入れ、
「実行が無料の世界」で運営する。
```

承継はその一形態にすぎない。同じ構造は他にもある。
- 地方の遊休不動産や設備を取得してAIで運営する
- 資格を取って独占業務の「署名」を売り、実行は全てAIにやらせる
- 既存のコミュニティや顧客基盤を持つ人と組み、その人の信頼にAI組織を乗せる

共通しているのは、**自分で作らない。既にある「増やせないもの」を押さえにいく。**

---

## 4. 一言で

価値の源泉は「作る力」から「欲しがる側と責任を持つこと」へ移る。
私なら、作るのではなく、AIで価値が跳ね上がるのに安く放置されている資産を、日本で最も大量に余っている場所（後継者不在の中小企業）から取りにいく。
