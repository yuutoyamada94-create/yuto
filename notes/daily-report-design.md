# 日報の漏れをなくす設計（運転手に「書かせない」日報）

作成日: 2026-10-03
前提: `data-to-profit-haulage.md` の続き。日報がデータの土台。ここが漏れると全部漏れる。
論点: 日報の漏れは「運転手が書かない」問題ではなく「書かせる設計」の問題。

---

## 0. 結論

- 運転手に日報を **書かせない** 。配車表＋伝票の写真＋位置情報から、日報を自動で組み立て、運転手は夕方に「OK」を押すだけにする。
- 漏れは「書き忘れ」ではなく **「予定と実績の差」として機械が見つけ、その日のうちに本人に聞く** 。翌日になると記憶が消える。
- 日報を運転手の **給料と手当に直結** させる。書く理由がない日報は漏れる。自分の金に関わる日報は漏れない。

---

## 1. なぜ漏れるか（運転手側の事情）

| 原因 | 中身 |
|---|---|
| 書く時間がない | 夕方、疲れて帰ってきて、紙に現場名・往復・処分先を書く。面倒 |
| 書いても誰も見ない | 翌月の請求にしか使われず、本人には何も返ってこない |
| 待機という概念がない | 「待たされた」は愚痴であって、記録する項目だと思っていない |
| 伝票をなくす・忘れる | 現場の受領印、処分場の受入票。ダッシュボードに溜まる、落とす |
| 現場名があいまい | 「○○の裏の現場」。得意先の正式名・支店・現場名が運転手には分からない |
| 書くと損することがある | 回転が少ない日、遅刻、燃料。正直に書くと怒られる |
| 紙と口頭 | 配車担当が口頭で指示し、紙に書く。元の指示が残っていない |

→ 「ちゃんと書け」と言っても直らない。**書かなくても出る形** にするしかない。

---

## 2. 漏れると何が起きるか（金に換算）

| 漏れ | 損失 |
|---|---|
| 往復数の漏れ | m3建ての現場で、運んだのに請求しない。1往復2〜3万円 |
| 待機時間の漏れ | 待機料を請求できない。1時間5,000円前後 |
| 処分先の漏れ | 処分費の原価が合わない。どの処分場にいくら払ったか追えない |
| 伝票の紛失 | 元請けから「証拠がない」と減額される |
| 拘束時間の漏れ | 2024年問題の上限超えを把握できない。事故時に会社の責任 |
| 給与の揉め事 | 日当・手当の根拠が曖昧で、運転手と揉める。定着に効く |
| 燃料の不整合 | 走った距離と給油が合わない |

日報が完全なら、同じ車・同じ人で売上が数%上がる。これが「人を増やさずに利益を上げる」の最初の実体。

---

## 3. 設計: 日報は「集める」のではなく「組み立てる」

### 3.1 材料（運転手が新しく書くものはゼロ）
| 材料 | どこから | 分かること |
|---|---|---|
| 配車表 | 配車担当が前日に組む（こちらが入力を引き受ける） | 誰が、どの車で、どの現場に、何台分、処分先はどこ、の **予定** |
| 現場の受領伝票の写真 | 運転手が積込のたびにLINEで送る | 往復1回の証拠。時刻付き |
| 処分場の受入票の写真 | 運転手が受入のたびにLINEで送る（自社処分場ならこちらで自動） | 往復1回の証拠。土質、量、時刻 |
| 位置情報 | 会社貸与スマホのLINE位置共有、またはデジタコ・ドラレコ（10tは装着済みが多い） | 到着・出発の時刻、現場と処分場での **停止時間＝待機** |
| 給油・ETC | 燃料カード、ETC明細 | 走行の裏付け |

### 3.2 組み立て
```
配車表（予定）  ＋  伝票写真（実績）  ＋  位置（時刻・待機）
        ↓
   AIが日報を自動で作る
   「山田 / 10t-3号車 / A現場→B処分場 / 3往復 / 現場待機 55分 / 処分場待機 20分 / 拘束 9h40m」
        ↓
   夕方17時、運転手のLINEに送る。「今日これで合ってる？」 → OKか修正
```
運転手がやるのは **伝票の写真を撮って送る（往復ごと）** と **夕方にOKを押す** の2つ。文字は書かない。

### 3.3 漏れの検知（その日のうちに）
| 検知 | 中身 | 動き |
|---|---|---|
| 予定と実績の差 | 配車表では3往復の予定なのに伝票が2枚 | 16時に本人へLINE「A現場の3回目の伝票、ある？」 |
| 伝票の片方がない | 受領伝票はあるが受入票がない | 「B処分場の受入票は？」 |
| 位置と伝票の不一致 | 位置では4回往復しているが伝票が3枚 | 「もう1往復あった？」 |
| 待機の未申告 | 位置で現場に90分停止しているのに待機の記録がない | 自動で待機90分として日報に載せ、本人に確認 |
| 拘束時間の超過 | 当月の累計が上限に近い | 配車担当と社長に事前通知 |

**翌日に聞かない。** 翌日には忘れている。その日の16〜17時に聞く。

### 3.4 給料とつなぐ（書く理由を作る）
- 日報の往復数・待機・拘束時間が、そのまま日当・手当・残業の計算に使われる。
- 月末に運転手本人へ「今月の稼働」を1枚で返す。「あなたは今月○往復、待機○時間、手当○円」。
- 待機手当を新設できれば最強。待機料を元請けに請求できるようになるので、原資が出る。運転手は待機を正直に申告し、会社は待機料を取れる。
- 「書くと損する」を消す。回転が少ない日の理由（待機、渋滞、処分場の混雑）が自動で残るので、本人が責められない。

---

## 4. 段階（運転手を驚かせない）

| 週 | やること | 運転手に頼むこと |
|---|---|---|
| 1 | 紙の日報はそのまま。伝票の写真をLINEで送ってもらう | 「伝票、写真で送って。紙も今まで通りでいい」 |
| 2 | 配車表（こちらが入力）と伝票写真を突き合わせ、漏れを夕方に聞く | 「夕方LINEで聞くから、返事して」 |
| 3〜4 | 自動日報を夕方に送り、OKだけ押してもらう。紙を減らし始める | 「これで合ってたらOK押して」 |
| 2ヶ月目 | 位置情報（デジタコかスマホ）で待機時間を自動化。待機料の請求を開始 | 「待機はこっちで分かるから、申告しなくていい」 |
| 3ヶ月目 | 月末に本人へ稼働1枚を返す。手当とつなぐ | 「今月の分、これ」 |

朝礼で5分、社長から言ってもらう。「伝票を写真で送るだけでいい。紙はなくす方向」。社長の言葉で始めることが大事。

---

## 5. 社長に見せる数字（漏れが金に変わる瞬間）

| 指標 | 導入前（推定） | 導入後 |
|---|---|---|
| 日報の提出率（当日中） | 60〜80% | 95%以上 |
| 伝票と往復数の一致率 | 不明 | 98%以上 |
| 待機時間の記録率 | ほぼ0 | 自動で100% |
| 待機料の請求額 | ほぼ0 | 月○○万円 |
| 月末締めから請求発送まで | 7〜10日 | 2〜3日 |
| 拘束時間の把握 | なし | 全員、日次 |

最初の月に「待機料として請求できる額」を1枚で出す。これが「日報が金になる」の最初の証拠。

---

## 6. 自社処分場があることの強み
受入票は自社で発行している。つまり **自社の車が自社の処分場に入る分は、運転手が何も送らなくても往復が確定する** 。
これが五幸の場合、日報の半分近くが自動で埋まる理由。他社のダンプ屋にはない条件。

---

## 7. 注意
- 位置情報は「監視」に聞こえる。「待機を証明して手当にする」「渋滞や混雑で責められないようにする」と、運転手の利益として説明する。
- デジタコがある車はそのデータを使う。無い車は会社貸与スマホ。私物スマホの位置共有は頼まない。
- 伝票の写真はピンボケや欠けが出る。AIが読めない時はその場で「もう一枚」を返す。
- 日報の形式を変えるのは最後。最初は「紙はそのまま、写真だけ追加」。
