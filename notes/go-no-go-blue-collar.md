# ブルーカラー市場に参入できるか（判定の仕方）

作成日: 2026-10-03
前提: これまでのノート全体。問いは「この会社に売れるか」ではなく「市場として参入可能か」。
知人の会社へのヒアリングは、その判定のための最も安い実験として使う。

---

## 0. 私の見立て

**参入は可能。ただし「ITの会社」としては不可能で、「現場に来る事務の会社」としてなら可能。**

| 可能な理由 | 不可能になる理由 |
|---|---|
| 需要は構造的（人手不足、承継、2024年問題、紙のまま）。空白地帯で競合がいない | 営業サイクルが長く、信頼でしか売れない。広告もSEOも効かない |
| 「人」の値段（事務員20万円）なら払う文化がある | 「ソフト」「AI」「効率化」には1円も払わない文化がある |
| 紹介が構造的に起きる業界（同じ現場、組合、処分場） | 最初の1社と1紹介が出るまで、半年〜1年の無収入期間がある |
| 知人の会社がある。最初の一歩が踏める | 知人以外に広げる時、「よそ者」の壁がもう一度来る |
| しきたりが堀になる。入れば抜かれない | しきたりに合わせられない人は入れない（朝、現場、電話、作業着） |

判定を分けるのは市場ではなく **自分たち** 。
「現場に朝行けるか」「社長と飲めるか」「3ヶ月無収入で紙を集計できるか」「AIと言わずにいられるか」。
市場は開いている。合うかどうかの問題。

---

## 1. ヒアリングで「市場」について聞くこと（この会社の話ではなく、業界の話）

専務・社長を「業界の先生」として、同業全体のことを聞く。

### 1.1 金を払うか
- 「同業の社長で、事務に人を雇えなくて困ってる会社、多いですか」
- 「事務員1人分（月20万円くらい）を外に払う、ってあり得ますか。どういう会社なら」
- 「逆に、こういうのは絶対払わない、っていうのは」
- 「今、外に払ってるものって何がありますか（税理士、社労士、行政書士、保険、システム）」

### 1.2 誰を信用するか
- 「業者が営業に来ることありますか。どういうのが来て、どうなりました」
- 「過去に何か入れようとして、ダメだった話ってありますか。何でダメでした」
- 「社長が人を信用する時って、何を見てますか」
- 「よそ者が入ってくるのに、一番嫌がられることは」

### 1.3 どう買うか
- 「新しいことを入れる時、誰が決めますか。社長？専務？奥さん？」
- 「決めるのに何が要りますか。知り合いの紹介？事例？補助金？」
- 「同業の社長同士って、どこで会いますか。組合？現場？飲み？」

### 1.4 紹介は起きるか
- 「もし自分のところでうまくいったら、同業の社長に話しますか。どういう言い方で」
- 「鶴見・緑・青葉で、同じ悩みを持ってそうな会社、何社くらい思い浮かびますか」
- 「処分場に持ち込む業者さんは何社くらい。その社長とは話しますか」

### 1.5 業界の変化
- 「2024年問題で何か変わりましたか」
- 「盛土規制法で、穴の方は厳しくなりましたか」
- 「ハウスメーカーからシステム入力しろとか、言われ始めてますか」
- 「後継者がいなくて困ってる同業、周りにいますか」

### 1.6 自分たちについて（正直に聞く）
- 「正直、僕らみたいなITの人間が来て、どう見えますか」
- 「何があれば信用してもらえますか」
- 「やめといた方がいい、と思うことはありますか」

## 2. Go / No-Go の判定基準

### 2.1 ヒアリング直後（この1件で分かること）
| 判定 | Go | No-Go |
|---|---|---|
| 払う意思 | 「事務員1人分なら払う会社はある」と言う | 「誰も払わない」「安ければ」しか出ない |
| 信用の条件 | 具体的に言える（現場に来る、紹介、約束を守る） | 「分からない」「ITは無理」 |
| 紹介の網 | 同業・持込業者の名前が5社以上出る | 名前が出ない、紹介は嫌がる |
| 業界の変化 | 2024年問題・盛土規制法・元請けの要求を実感している | 「何も変わってない」 |
| 自分たちの見え方 | 「現場に来るなら」など条件つきで受け入れ | 「来ても無駄」 |

5項目中3つ以上がGoなら、次の実験に進む。

### 2.2 次の実験（60〜90日）
| 実験 | 合格ライン |
|---|---|
| 紙を預かって3枚の一覧を出す | 専務か社長が「初めて見た」と言う |
| 30日無料の事務員を置く | 31日目に有料で続く |
| 紹介を1件もらう | 90日以内に同業・持込業者を1社紹介される |
| 自分たちの持続性 | 90日間、週2回以上現場に行けた。AIと言わずに済んだ |

4つ中3つで、参入を決める。1つ以下なら撤退を検討。

### 2.3 参入後の確認（6〜12ヶ月）
| 指標 | 合格ライン |
|---|---|
| 有料顧客 | 6ヶ月で3社、12ヶ月で8〜10社 |
| 紹介比率 | 新規の半分以上が紹介 |
| 継続率 | 12ヶ月で90%以上 |
| 1社あたり月額 | 15〜25万円が維持できている |
| 業種の型 | 2社目以降の導入が1社目の半分の工数 |

## 3. ITから来る人が、この市場で失敗する典型

| 失敗 | 中身 | 防ぎ方 |
|---|---|---|
| 製品を先に作る | 使われないアプリを作って、営業に行く | 作らない。紙とLINEとシートで10社回す |
| 言葉が合わない | AI、DX、効率化、KPI | 業種の言葉だけ使う。回転、待機、受入、立米、車建て |
| 現場に行かない | リモートで提案書を送る | 朝、作業着で、車庫に行く |
| 速さを求める | 3ヶ月で決着をつけたがる | 1社目に6ヶ月、紹介に1年かける |
| 横に広げる | 建設も運送も介護も | 1業種1地域。鶴見・緑・青葉の残土・産廃 |
| 業界の人を横に置かない | 自分だけで行く | 元運転手、元事務、元配車担当をパートで |
| 金融・補助金で釣る | 「補助金で安くなります」 | 言わない。補助金目当ての社長は網を汚す |

## 4. 参入の最小構成

| 要素 | 内容 |
|---|---|
| 人 | 自分（DRM・AI・設計）＋ 業界の人1名（パートでいい。元運転手・元事務） |
| 道具 | LINE、スプレッドシート、AIの読み取り、電話転送 |
| 商品 | 事務員つき月15〜25万円。最初の30日無料 |
| 地域・業種 | 横浜北部の残土・産廃・ダンプ。1社目は知人の会社 |
| 資金 | 自分の生活費6ヶ月分。会社の持ち出しは道具代だけ |
| 期限 | 90日で判定、12ヶ月で10社 |

---

## 5. 一言で

参入はできる。市場は開いていて競合はいない。
決めるのは市場ではなく、自分たちが「現場に来る事務の会社」になれるか。
知人の会社のヒアリングで「払うか、誰を信用するか、紹介は起きるか」を業界の話として聞き、5項目中3つでGo。
90日で紙→一覧→30日無料→有料→紹介1件、の4つ中3つで参入を決める。

## 6. 修正: 「現場に行く」の中身を分ける（派遣ではない）

### 6.1 混ざっていた2つ
| | 中身 | 必要な回数 |
|---|---|---|
| 信頼のための訪問（営業・関係） | 初回ヒアリング、車庫・処分場の見学、社長の聞き取り、月末の初回並走、年数回の顔出し | 1社目で3ヶ月に3〜5回。紹介先は1〜2回。以後は四半期に1回の顔出し |
| 業務の提供（デリバリー） | 伝票の読み取り、日報生成、請求下書き、入金消込、電話転送の受付、配車表の転記、月次報告 | **ゼロ。全部リモート** |

「現場に行け」と言っていたのは前者。後者は行かない。派遣でも常駐でもない。

### 6.2 現場側の「手」は誰か
リモートで回すには、現場に「写真を撮る人」「紙を箱に入れる人」「確認する人」が要る。それは **こちらの人ではなく、客側の人** 。
| 客 | 現場側の手 |
|---|---|
| 五幸 | 奥さん（事務を引き継ぐ人）。承継の構造そのものが、現場側の手を用意している |
| 事務がいる会社 | その事務 |
| 事務がいない会社 | 配車担当か職長が伝票ボックスを撮る。朝礼で社長が一言言えば済む |

こちらは「リモートの事務エンジン＋電話の控え＋月次の数字」。客側は「写真と確認」。この分担なら、10社でも20社でも、こちらの人は増えない。

### 6.3 派遣との違い（法的にも）
- 労働者派遣は許可が要り、客の指揮命令下で働く。やらない。
- こちらは業務委託。成果物（日報、請求書の下書き、一覧、受付記録）を納める。客の指示で動く人を置かない。
- 「常駐」「派遣」「出向」という言葉は使わない。「事務員つき」は商品名であって、人を置く意味ではないと契約書で明確にする。

### 6.4 「ただの事務」ではない理由（自分への確認）
事務は入口。残るのは「1往復1行のデータ」「金の流れの入口」「承継の型」。
ただし、入口の事務そのものに魅力を感じないなら、それは本物の信号。3〜6ヶ月は事務の顔で過ごすことになる。
